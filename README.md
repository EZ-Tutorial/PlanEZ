# PlanEZ 🛩️

**PlanEZ** is a **multiplayer aerial combat** game made with **Godot**.  
Players pilot planes in the same arena and **shoot each other down** in fast-paced dogfights.

## 🕹️ Gameplay
- **Multiplayer dogfights**: fight against other players in real time
- **Plane controls**: fly, turn, accelerate, and dodge incoming fire
- **Weapons**: shoot opponents to damage and destroy their planes
- **Goal**: outfly and outshoot everyone else
